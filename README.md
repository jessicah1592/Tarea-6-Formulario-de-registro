# Tarea-6-Formulario-de-registro

Formulario de registro para plataforma de e-commerce desarrollado con React y Tailwind CSS.

## Características

- Gestión de estado con useState para nombre de usuario, correo electrónico y contraseña
- Validación de datos en tiempo real
- Botón de envío condicionado a la validez de todos los campos
- Mensaje de confirmación y bienvenida personalizada tras registro exitoso
- Diseño moderno e interactivo con Tailwind CSS
